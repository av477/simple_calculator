# simple_calculator
simple calculator for functions such as addition, subtraction, multiplication, and division.

Run the calculator.py from VSCode, it will prompt with following options to choose from.

Simple Calculator For Basis Mathematics Operations
1. Enter 1 for Addition
2. Enter 2 for Subtraction
3. Enter 3 for Multiplication
4. Enter 4 for Division
5. Enter 5 to Exit
